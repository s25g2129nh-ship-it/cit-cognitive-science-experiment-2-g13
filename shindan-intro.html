就活16タイプ診断

20の質問に答えると、あなたに合う就活の方向性を4つの軸で調べて、16タイプのどれに近いかを教えてくれる診断です。

診断をはじめる
20問・約3分登録不要無料

この診断で分かること

  • あなたのタイプ:16タイプのうち、どれに一番近いか
  • 4つの軸の傾向:それぞれの軸で、どちらにどれくらい寄っているか(割合で表示)
  • 向いている職種の例:タイプに合いそうな理系の職種
  • あなたの次の一歩:今週からできる、具体的なやること3つ
  • 相性のいいタイプ:一緒に働くと強い、自分にない視点を持つタイプ

4つの軸

質問への答えから、次の4つの軸でどちらに寄っているかを調べます。4つの組み合わせで、16タイプになります。

文字軸意味
H / T関わる対象H = ヒト(人と向き合う)、T = モノ・技術(技術と向き合う)
S / V働く環境S = 安定(大きな組織で着実に)、V = 挑戦(変化のある環境で)
D / B専門性D = 深く(スペシャリスト)、B = 広く(ジェネラリスト)
P / A進め方P = 計画(計画を立てて進む)、A = 行動(動きながら考える)

たとえば「TSDP」は、モノ・技術(T)× 安定(S)× 深く(D)× 計画(P)のタイプです。

答え方

  1. 質問を読んで、「とてもそう思う」から「まったくそう思わない」までの5段階から選びます。
  2. 考え込まずに、直感で答えてください。正解・不正解はありません。
  3. 選ぶと自動で次の質問に進みます。「前の質問」ボタンで戻って直せます。
  4. 20問すべて答えると、結果が表示されます。

パソコンでは、キーボードの1〜5キーでも答えられます。

診断のあとは

結果ページの「次の一歩」から1つ選んでやってみましょう。気になる職種は職種ガイドで仕事内容を、いつ何をするかは就活ロードマップで確認できます。

注意

  • この診断は、千葉工業大学の授業のプロジェクトとして学生が作ったものです。結果は、方向性を考えるきっかけとして使ってください。
  • 回答はあなたのブラウザの中だけで計算され、どこにも送信・保存されません。
  • この診断は、MBTI®とは関係ありません。
