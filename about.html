このサイトについて

「CIT就活」は、就活について何も知らない理系学生が、最初の一歩を踏み出せるように作ったサイトです。

作った人

千葉工業大学「認知情報科学実験2」のグループ13(6人)が、授業のプロジェクトとして制作しました。

アンケート結果

2026年10月に、就活を始める前の2年生と、就活中・就活を終えた先輩にアンケートをとり、両者の違いからこのサイトに載せる情報を決めました。

  • 就活前(学部2年生)：81人
  • 就活中・就活を終えた人(学部3年・4年・大学院生)：18人

選考対策(ES・面接・Webテスト)は、先輩も2年生と同じくらい知りたがっていたため、選考対策のページを作りました。一方で、資格を気にしている2年生は多いものの、先輩で知りたかった人はわずかでした。

就活タイプチェックについて

タイプチェックは「関わる対象(ヒト / モノ・技術)」「働く環境(安定 / 挑戦)」「専門性(深く / 広く)」「進め方(計画 / 行動)」の4つの軸で、あなたの傾向を見るものです。

どの理論をもとにしているか

軸もとにした考え方
関わる対象(ヒト / モノ・技術)ホランドの職業興味理論。人と関わる仕事に興味があるか、物や技術を扱う仕事に興味があるか
働く環境(安定 / 挑戦)シャインのキャリア・アンカー。「保障・安定」と「起業家的創造性・挑戦」のどちらを大事にするか
専門性(深く / 広く)シャインのキャリア・アンカー。「専門・職能」と「全般管理」のどちらを目指すか
進め方(計画 / 行動)2つの理論にはない、就活の進め方を見るためにグループで加えた軸。計画を立ててから動くか、動きながら考えるか

タイプの出し方

  • 1つの軸につき5問、全部で20問です。「とてもそう思う」から「まったくそう思わない」までの5段階で答えます。
  • 軸ごとに点数を足して、多かった方の文字がタイプになります(例：ヒトよりモノ・技術の点が多ければ T)。
  • 「全部そう思う」と答える癖で結果が偏らないように、左右どちらの向きの質問も混ぜています。
  • 左右の差が小さい(40〜60%)軸は、結果ページで「どちらにも近い」と表示し、その軸だけ反対にした「近いタイプ」も紹介します。

職業興味の理論(ホランドの職業興味理論など)やキャリア・アンカーの考え方を参考にしていますが、学生が作ったものなので、結果はあくまで方向性を考えるきっかけとして使ってください。

このタイプチェックは、MBTI®とは関係ありません。
